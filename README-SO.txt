BS ENTERTAINMENT — WEBSITE BILOW AH
===================================

WAXA KU JIRA
- index.html: bogga website-ka
- style.css: naqshadda iyo mobile responsive layout
- app.js: shaqada website-ka iyo admin demo
- Admin panel: ku dar/tirtir projects iyo xubnaha kooxda
- Xogta demo-ga waxay ku kaydsantaa browser-ka (localStorage)

SIDA LOO FURTO
1. Soo saar ZIP-ka (Extract).
2. Fur galka bs_entertainment_website.
3. Taabo index.html si browser-ka loogu furo.
4. Internet looma baahna si layout-ka loo arko; Google Fonts waxay u baahan karaan internet.

ADMIN PANEL
1. Guji badhanka "Admin" ee geeska hoose.
2. Password-ka bilowga ah: BSstudio2026!
3. Gal Settings si aad u beddesho password-ka.
4. Projects iyo Team tabs waxaad ku dari kartaa ama ka tirtiri kartaa xogta.
5. Xogta waxaa lagu kaydiyaa browser-ka aad ku furtay.

MUHIIM — KA HOR INTA AAN INTERNETKA LA GELIN
- Tani waa frontend/demo version. Password-ka admin-ka waxaa lagu hubiyaa JavaScript,
  sidaas darteed qof aqoon u leh browser-ka wuu dhaafi karaa. Ha u isticmaalin xog sir ah.
- localStorage wuxuu ku shaqeeyaa browser-ka qalabkaaga oo keliya; xogtu qalab kale iskuma gudubto.
- Upload dhab ah oo sawirro/video ah, accounts, database iyo admin ammaan ah waxay u baahan
  yihiin backend iyo adeeg kaydin (tusaale Supabase ama server kuu gaar ah).
- Email-ka tusaalaha ah bsentertainment@example.com ku beddel email-ka kooxda.
- Ku dar social media links-ka rasmiga ah marka la helo.
- Isticmaal oo keliya anime, sawirro, muusig iyo muuqaallo aad fasax u haysato inaad daabacdo.
- Ha soo gelin xogta gaarka ah ee xubnaha adigoon oggolaansho ka haysan.
